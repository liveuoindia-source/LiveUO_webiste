Shoppers are impatient, especially on phones. A product page that takes several seconds to appear loses a share of visitors before they've seen anything. A checkout that hesitates after each tap loses buyers who had already decided. Speed is a sales feature, not a technical detail.

## Measure on real conditions

Desktop tests on office Wi-Fi flatter your store. Measure:

- on a **mid-range Android phone**
- over a **mobile network**
- for **key pages** — home, category, product, cart, checkout

Tools like Google PageSpeed Insights show lab results and, where available, field data from real users. Search Console reports Core Web Vitals across your site.

## Core Web Vitals in plain language

| Measure | What it means | Typical cause when poor |
|---|---|---|
| Largest Contentful Paint | How fast the main content appears | Large images, slow server |
| Interaction to Next Paint | How quickly the page responds to taps | Heavy JavaScript |
| Cumulative Layout Shift | How much the page jumps while loading | Images without dimensions, late-loading banners |

## Fixes that usually matter most

### 1. Images

The biggest win on most stores.

- compress images and serve modern formats like WebP
- size images for the screen they're shown on
- lazy-load images below the first screen
- set width and height so the layout doesn't jump

### 2. Third-party scripts

Chat widgets, trackers, review apps, heatmaps and social embeds each add weight. Audit them:

- remove what nobody uses
- load the rest after the main content
- keep checkout as light as possible

### 3. Theme and plugins

Themes packed with sliders, animations and features you don't use slow every page. Simplify, and remove unused plugins.

### 4. Hosting and caching

- use hosting sized for your traffic
- cache pages and assets
- use a CDN to serve images and files from locations near your customers

### 5. Fonts

Limit the number of font families and weights, and load them efficiently so text appears immediately.

## Prioritise pages that earn money

Start with the pages most visitors see and the pages closest to purchase:

1. product pages
2. category pages
3. checkout
4. home page

A fast home page with a slow checkout still loses orders.

## Keep it fast

Speed tends to degrade as new apps, banners and scripts are added. Set a rule: every new script or plugin must justify its cost in speed, and check speed monthly.

## Speed and search

Page experience is one of many signals search engines use. A faster site won't outrank a more relevant one on speed alone, but slow pages are a disadvantage — and they frustrate the visitors search sends you.

## Quick checklist

- images compressed, sized and lazy-loaded
- unused scripts and plugins removed
- remaining scripts loaded after main content
- caching and CDN in place
- layout stable while loading
- checkout tested on a mid-range phone over mobile data

A fast store feels more trustworthy, converts better and costs less in wasted ad clicks. Most stores can become dramatically faster with a few focused fixes — no redesign required.
