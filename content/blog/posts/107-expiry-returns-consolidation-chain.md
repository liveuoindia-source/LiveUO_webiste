Expiry is an unavoidable cost of running pharmacies. What's avoidable is losing the credit that suppliers and manufacturers would have given back. In a chain, expiry returns often fall apart at the branch level: a branch misses a return window, a box sits in a back room for months, or paperwork can't be matched to the original purchase.

Consolidating returns centrally turns a scattered task into a managed process.

## The process

### 1. Identify early

Every month, each branch reviews stock expiring within a set window — long enough to act. The system lists items by batch with quantity and value.

### 2. Try to sell or transfer first

Before returning:

- move stock to branches where it sells faster — see [inter-branch transfers](/resources/blog/inter-branch-stock-transfer-pharmacy/)
- prioritise it in dispensing where appropriate
- offer it to institutional customers if suitable

### 3. Pull for return

Stock that won't sell in time is pulled from shelves into a non-saleable "returns" location in the system, with batch details.

### 4. Send to central

Branches transfer return stock to the warehouse or head office with a transfer document. The central team confirms receipt by batch.

### 5. Consolidate

Central groups returns by supplier or manufacturer, and by batch, matching each to purchase records.

### 6. Claim

Returns are sent to suppliers or manufacturers within their policy, with the required documents. Each claim is tracked until a credit note is received.

### 7. Write off what can't be returned

Items outside policy are written off and disposed of according to the rules, with records kept.

## Know the policies

Return terms vary by supplier and manufacturer: how close to expiry, how long after, whether full or partial credit, which documents are needed. Keep a summary in the system so the central team knows each deadline.

## Batch records make it possible

Claims need item, batch, expiry, quantity and the original purchase invoice. If branches don't record batches accurately at purchase and transfer, claims become guesswork and many are rejected.

## Track recovery

| Measure | Why |
|---|---|
| Near-expiry value by branch | Shows where problems start |
| Value returned vs claimed | Shows process completeness |
| Credit received vs claimed | Shows supplier performance |
| Claims pending | Shows follow-up needs |
| Write-offs | Shows the true cost |

## Prevent the next one

Use expiry data to fix buying:

- items repeatedly returned are overstocked — lower reorder levels
- schemes on slow items often end up as returns
- suppliers sending short-expiry stock should be challenged at receipt

See [reducing expired-stock write-offs](/resources/blog/reduce-expired-stock-write-offs-pharmacy/).

## The payoff

A chain that consolidates returns recovers more credit, misses fewer deadlines and has a clear picture of what expiry really costs. Combined with better buying, it turns expiry from an accepted loss into a managed, shrinking line in the accounts.
