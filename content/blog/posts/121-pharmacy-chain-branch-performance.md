Once a pharmacy chain has several branches, the owner naturally asks: which ones are doing well, and why? The easy answer — compare sales — is usually the wrong one. A busy branch on a main road will outsell a quiet neighbourhood store regardless of how well either is run.

Fair comparison looks at how well each branch runs, not just how big it is.

## Measures that compare fairly

| Measure | What it shows |
|---|---|
| Sales growth % | Momentum, independent of size |
| Gross margin % | Pricing and buying discipline |
| Discount % of sales | Counter discipline |
| Stock days | Buying efficiency — how many days of sales are on the shelf |
| Near-expiry % of stock | Expiry control |
| Audit difference % | Stock accuracy |
| Average bill value | Service and range |
| Stock-outs of key items | Availability for regular patients |
| Repeat customer share | Patient loyalty |

## Put them on one page

A monthly branch scorecard:

| Branch | Growth | Margin | Discount | Stock days | Near-expiry | Audit diff |
|---|---|---|---|---|---|---|
| Branch A | | | | | | |

Highlight values well above or below the chain average.

## Context matters

Before drawing conclusions, consider:

- location — hospital-adjacent, residential, high street
- age — new branches take time to build
- customer mix — chronic patients, walk-ins, institutional
- local competition

A branch with lower margin near a large discounter may be doing the right thing.

## Use comparison to learn

The most valuable question isn't "who's worst?" but "what does the best branch do differently?"

- the branch with the lowest expiry may have a better near-expiry routine
- the branch with the highest repeat share may run refill reminders well
- the branch with the best audit accuracy may receive deliveries more carefully

Share these practices across the chain.

## Act on outliers

For a branch well outside the normal range:

1. check the data — errors are common causes
2. discuss with the branch manager
3. agree specific actions
4. review next month

## Data you can trust

Fair comparison needs consistent data:

- one item master and one set of definitions — see [consolidated reporting](/resources/blog/consolidated-reporting-pharmacy-chain/)
- accurate stock from regular cycle counts — see [cycle counting](/resources/blog/cycle-counting-pharmacy-chain/)
- consistent pricing — see [keeping prices consistent](/resources/blog/pharmacy-chain-price-master-control/)

## Involve branch managers

Share each branch's scorecard with its manager, explain the measures, and set targets together. Managers who understand how they're measured — and believe it's fair — usually improve the numbers themselves.

## The result

Fair branch comparison turns a chain's data into a management tool. It shows where to help, what to copy and where to invest — and it rewards good management rather than good locations.
